# Docs

Knowledge home for this repo. Agents: read the relevant files here before planning or starting a task.

- `plans/` — implementation plans (this dir holds the executed improvement plan; new plans land here too).
- `research/` — research findings and measurement baselines (e.g., Lighthouse/axe QA numbers).
- `notes/` — session notes and scratch (mutable; not authoritative).
- `impeccable/` — design direction decision artifacts (impeccable payloads).

Authoritative docs live at the root: `PRODUCT.md` (product truth), `AGENTS.md` (context router), `agent_rules/` (agent rules).
