# Agent Rules

Core rules for agents working in this repo. The root `AGENTS.md` routes to these lazily — read only the file(s) matching your task, never all of them. Loaded rule files are mandatory instructions.

| File | Domain |
|---|---|
| content-truth.md | Content accuracy, resume facts, copy policy |
| site-standards.md | SEO / AEO / accessibility invariants |
| git-workflow.md | Commits, merges, branch hygiene |
| board-workflow.md | Kanban board loop + defer-to-user protocol |

Keep rule files short and link to evidence (PRODUCT.md, skills) instead of duplicating it. Add a new file here (and a row in root `AGENTS.md`) when a new domain needs rules.
